# Game Boy hardware database

~~Site source code for https://gbhwdb.gekkio.fi~~

**This repository is deprecated and the site implementation is no longer open source**. Don't worry, the site itself is still up and all data is still licensed under CC 4.0 Attribution-ShareAlike.

Why?

1. having all the site data in the git repository simple doesn't scale. Git LFS makes it possible to store binary blobs (= photos) in a git repository but somebody has to pay for that storage and bandwidth. In 2026 this became unsustainable because people were cloning/forking this repo much more than before (probably due to AI use), and it's the original repo owner (= me) who pays for the storage/bandwidth.
2. people use AI to copy open source projects, and I have no desire to show the site sources anymore
